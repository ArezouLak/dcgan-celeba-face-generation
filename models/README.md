Model Weights
The training script saves two checkpoints:
```text
generator.pth
discriminator.pth
```
These files store the PyTorch `state_dict` for the trained DCGAN generator and discriminator.
Model weights are not included in this repository. They can be regenerated by running:
```bash
python src/train.py
```
After training, new face samples can be generated with:
```bash
python src/generate.py
```
